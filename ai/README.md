# AI Classification

This directory is reserved for the AI-based RF signal classification stage of the project.

The overall architecture is designed to use extracted RF/DSP features as inputs to a classification model.

## Planned Inputs

- FFT spectral features
- Peak frequency
- Peak magnitude
- Signal magnitude characteristics

## Status

AI classification is currently planned as the next development stage.

The current repository focuses on the implemented DSP processing and Vitis HLS acceleration components.
